Features

Five things you usually do by trial and error.

01

Diagnosis in a minute

WorkspaceFPV reads the configuration over MSP and checks it against a set of rules: ESC protocol, bidirectional DShot, voltage per cell, arming disable flags. With an AI API key it fills in the rest and suggests CLI commands. You always see the list of what was checked.

What I checked5 rules
  • Motor mapping: OK
  • 6S voltage 24.9 V: OK
  • Protocol: DShot300
  • Bidirectional DShot: disabled
  • Arming disabled: RXLOSS, ARMSWITCH
set motor_pwm_protocol = DSHOT600
set dshot_bidir = ON
02

ESC without guessing

You pick the DShot protocol from a list and the change is written with a CLI command. WorkspaceFPV reminds you that bidirectional DShot needs Bluejay, BLHeli_32 or AM32 and does not work on stock BLHeli_S. The motor test only starts after you tick “Props removed”. It has a STOP button and stops by itself when the connection drops.

03

Autotune from a log

Drop in a CSV from blackbox_decode or Blackbox Explorer. WorkspaceFPV computes the gyro spectrum (0–500 Hz, peaks labelled) and the step response with measured overshoot, then shows your current PIDs next to the suggested ones, along with ready-made set p_roll= commands.

04

ELRS without the stress

The ELRS version cannot be read from the flight controller, so you enter it by hand. WorkspaceFPV walks you through a checklist: 3.x compatibility of transmitter and receiver, binding phrase, LBT/FCC. Then it opens the official ELRS Web Flasher. Flashing from inside the app is planned.

ReceiverELRS 3.4.3
  • Serial protocol: CRSF
  • Transmitter and receiver: same 3.x line
  • Binding phrase: check on both devices
  • 3.5.1 is available. Back up your options before flashing

05

Nothing changes without your consent

Before any command reaches the controller, WorkspaceFPV saves a diff all backup and shows the full list of changes for you to confirm. Only then does it run save and reconnect. Your API key stays in your browser or app and goes nowhere except Anthropic.

Install

Download, plug in, check.

REQUIREMENTS

  • Windows 10/11 64-bit or Chrome / Edge 89+ with WebSerial
  • USB data cable (not a charge-only one)
  • Betaflight 4.3+ on the flight controller
  • Anthropic API key: optional. Without it the rule-based diagnosis still works.
  1. Download the installer. WorkspaceFPV-Setup.exe from GitHub Releases. Or open the browser version.
  2. Run it. The app is not code-signed, so SmartScreen may ask: More info, Run anyway.
  3. Plug in the drone. USB cable to the flight controller, Betaflight Configurator closed (it holds the port). Props off.
  4. Click Connect. No drone at hand? Demo mode shows a simulated FC.
